GR IIIx HDF 1.60 · GR Mod T4F1 / 可选柔焦固件 T4-SF1
2026-10-11

此版本沿用 T4 的九画幅、完整 RAW 和取景处理。
用户已确认 T4 频闪消失；偶发抖动目前无法复现，未宣称修复抖动，未改动防抖。
不启用柔焦时，GR Mod 导出的固件与原 T4 逐字节一致。

本次新增
1. 开放“开启工厂菜单”“影像控制”“关机画面”页面，不再强制停留在长宽比。
2. IIIx 1.60 专属 Script 入口文件，可导出或写卡。
3. IIIx HDF 关机画面的制作、轮换、恢复原厂图。
4. 可选柔焦固件 T4-SF1。不会占用原有 ADJ 功能。

新增功能经过本地校验和原厂函数测试，仍需相机确认。
这不是 GR IV 所有功能已全部移植的声明。LUT/XMP、自定义名称和图标、日期水印、
独立 ADJ 柔焦菜单尚未开放。GR IV Monochrome 六种风格尚未在 IIIx 中发现可直接解锁的实现。

柔焦测试
• 只使用 T4-SF1 目录里的 fwdc243b.bin，不要把名字改成 GR IV 的 fwdc248b.bin。
• 和之前 T4 一样，把更新文件放到相机用的 SD 卡根目录，按原有方法更新同版本 1.60。
  更新前确保电量充足；更新过程中不要断电、拔卡。取景与 RAW 基础行为仍是 T4。
• 刷入后：ADJ → 影像控制 → 详细设置 → 清晰度。
  0：原厂效果；−1：弱柔焦；−2：中；−3：强。
  −4 和 +1…+4 保持原厂清晰度效果。原生不允许调清晰度的风格仍遵循原厂限制。
• 固定相机、固定曝光和焦点，先用“标准”影像控制，依次拍 0、−1、−2、−3。
  比较拍摄后的 JPG；柔焦不用于待机取景。保留 JPG+RAW，检查 RAW 仍为完整 3:2。
• 在 GR Mod“影像控制”页关闭柔焦后导出，得到原 T4，可刷回原有清晰度。
  如要完全回原厂，使用“导出原厂固件”；刷回后将清晰度重新设为 0。

Script 与关机画面
• 先打开 IIIx 官方 1.60 文件，确认机型为 GR IIIx HDF。
• “开启工厂菜单”页导出两份文件：DEVELOP.MOD 和 00078490.609。
  放 SD 根目录后按住 MENU 开机，在菜单里只把 Script 设为 Enable，然后关机。
• 回到 GR Mod“关机画面”页，加入图片或“原厂画面”，裁切确认后导出/写卡。
  图片为 720×480，每张精确 7,264 字节；复杂照片会明显降低质量，简单图形更合适。
  此流程沿用项目的 FAT32 / MBR 卡要求；本次 256 GB exFAT 样片卡未格式化、未写入此类脚本。
• 图片卡根目录有 GBR1.JPG 等和 GBRIDX.TXT，script/startup.ttl 在 script 文件夹内。
  使用应用写卡时，冲突的更新文件和入口文件会移入 GRMOD/parked-…，照片目录不动。
• 脚本只在核对 IIIx HDF 机型与内部图片大小后复制；卡上有更新文件时不运行。
• 恢复原厂关机图：在“关机画面”里移除其他条目，只保留“原厂画面”，导出/写卡，
  装卡开机一次再关机。停止轮换可在卡根目录放置 GBRSTOP.TXT；这只停止轮换，
  不会自动恢复已写入的内部图片。先恢复原厂图，再移开 script/startup.ttl。
• “恢复关机画面”按钮恢复的是应用备份的图片卡配置，与恢复相机原厂图片是两件事。

未适配项目的依据
• LUT/XMP：IIIx 缺少 Cinema Yellow/Green。其色彩表为 26 项单套结构，IV 是 34 项×3 套，
  矩阵、多轴与曲线的选择流程也不同。不能覆盖 IV 地址或把 IV 的颜色标定作为 IIIx 实测。
• 独立 ADJ 柔焦：IIIx 的 ADJ 槽仍使用闪光补偿等功能，不能套用 IV 借用闲置槽的方案。
• 日期水印：JPEG 编码入口已找到，但时钟上下文、图像描述及新菜单仍需完整验证。
• Monochrome：IV 共用固件里存在的隐藏风格，在 IIIx 中未找到同等开关；不能称为已解锁。

本次所有产物只保存本机，未写 SD，未替用户执行刷机。
